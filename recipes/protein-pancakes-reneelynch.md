# Protein Pancakes

**Source:** reneelynch_naturopath (Instagram)
**Added:** 2026-07-26

## Ingredients

| Ingredient | Quantity |
|---|---|
| Eggs | 2 |
| Banana (mashed) | ½ |
| True Protein French Vanilla | 1 scoop |
| Baking powder | ½ tsp |
| Buckwheat flour | 3 Tbsp |
| Vanilla extract | 1 tsp |
| Salt | Pinch |
| Butter | For cooking |
| **Topping** | |
| Chobani low-fat yoghurt | 2–3 Tbsp |
| Berries | Handful |

## Method

1. Mash banana. Whisk in eggs.
2. Add all remaining ingredients.
3. Cook over medium heat with some butter.
4. Serve with Chobani low-fat yoghurt and berries.

## Macros (label-verified from Reneelynch post)

| | Full batch (2 large pancakes) | Per pancake |
|---|---|---|
| **Protein** | 47g | ~23.5g |
| **Carbs** | 34g | ~17g |
| **Fat** | 12g | ~6g |
| **Calories** | 449 kcal | ~224 kcal |

*Reneelynch note: "These are dense. Maybe you want to split the servings into 2, or if you've lifted some heavy weights this will hit the spot." Sub Chief Whey for True Protein → similar macros (both ~23–24g P/scoop).*
